# Pulse AI 🫀⚡

**Pulse AI** is an intelligent mobile health and biometric tracking application designed to translate raw wearable data into actionable daily recovery insights. Featuring sleek, dark-mode home-screen widgets and real-time heart rate monitoring, it helps athletes and everyday users optimize their training load and recovery.

## ✨ Key Features
* **Daily Readiness Score:** AI-driven recovery calculation combining Heart Rate Variability (HRV), Resting Heart Rate (RHR), and sleep quality metrics.
* **Smart Heart Rate Zones:** Precision zone tracking powered by the **Heart Rate Reserve (HRR)** method for accurate workout intensity monitoring.
* **Interactive Home-Screen Widgets:** Glanceable dark-themed widgets displaying live heart rate trends and daily readiness status.
* **Biometric Trend Analytics:** Clean visualizations to track long-term cardiovascular fitness, recovery baselines, and physiological strain.

## 🛠️ Tech Stack
* **Framework:** Flutter / Dart
* **Data & Analytics:** Wearable biometric sync & HRR/HRV algorithmic scoring
